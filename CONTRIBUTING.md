# Contribuer à VoixLocale

Les signalements de bugs et propositions d’amélioration sont bienvenus.

Avant de proposer un changement :

1. vérifiez qu’aucun enregistrement vocal, modèle ou MP3 personnel n’est ajouté ;
2. construisez l’application avec `./scripts/build_app.sh` ;
3. exécutez les tests avec `swift test --disable-sandbox` ;
4. décrivez clairement le comportement attendu et le résultat observé.

Toute utilisation d’une voix doit respecter le consentement explicite de la
personne concernée.
